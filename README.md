# Car Photo Collector

インストール不要で使える、車種別の写真収集用ローカルアプリです。

## すぐ開くURL

スマホ・PC共通:

https://kys-code.github.io/car-photo-collector/

GitHub上のURLメモ:

https://github.com/kys-code/car-photo-collector/blob/main/MOBILE_URL.md

別PC・スマホから開けるURLメモページ:

https://kys-code.github.io/car-photo-collector/links.html

## 使い方

1. `index.html` をブラウザで開きます。
2. メーカーと車種プリセットを選ぶか、車種名を直接入力します。
3. 必要なら年式を選びます。
4. 検索すると、外装・内装の候補写真が表示されます。
5. `外装をもっと見る` / `内装をもっと見る` を押すと追加候補を読み込みます。
6. 必要な写真を選択します。
7. `CSV保存`、`HTML保存`、または `選択画像をZIP保存` で保存します。
8. よく検索する車種は `検索車種をお気に入り登録` で保存できます。

## 検索車種のお気に入り

検索する車種名と年式をブラウザ内に保存できます。登録した車種は右側の `検索車種のお気に入り` からすぐ再検索できます。

これは写真のお気に入りではなく、検索条件としての車種お気に入りです。お気に入りはブラウザごとの保存です。スマホとPC、別PCでは共有されません。別端末でも同じ車種を使いたい場合は、それぞれの端末で登録してください。

## スマホで使う場合

このアプリは現在ローカルHTMLとして保存されています。PC内の `index.html` を直接開く方式では、スマホからはそのまま利用できません。

スマホで使う場合は、以下のいずれかの形にしてください。

- GitHub Pages、Vercel、Netlify などで公開URLを作る
- Google Driveなどに置き、スマホから開ける共有リンクを作る
- PCでローカルサーバーを起動し、同じWi-Fi上のスマホからPCのIPアドレスで開く

スマホメインで使う場合は、公開URL化する方法が一番扱いやすいです。

## 検索について

検索元は Wikimedia Commons です。車種名そのものだけでなく、年式、外装、内装、dashboard、cabin、front、rear、side、motor show など複数の語を組み合わせて検索します。

右側には Google画像検索、Bing画像検索、Wikimedia Commons の追加検索リンクも表示されます。

## 注意

- アプリの起動にインストールは不要ですが、検索と画像保存にはインターネット接続が必要です。
- ZIP保存は選択済みのJPEG/PNG画像を取得してまとめます。画像提供元のCORS制限により、一部画像は保存できない場合があります。
- 写真を利用する場合は、保存された出典ページでライセンスを確認してください。
